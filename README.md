## What it does

Writing good prompts is surprisingly hard. Small wording changes cause large output swings, constraints are easy to forget, and there's no systematic way to iterate across a team.

**PromptTune** solves this with a guardrails-first approach:
- Input your prompt and define hard constraints (tone, length, format, boundaries)
- The tool refines the prompt to satisfy all constraints without breaking intent
- Powered by **GPT-4o-mini** on the backend for fast, cost-efficient optimization

Built for AI PMs, prompt engineers, and developer teams who ship LLM-powered features.
